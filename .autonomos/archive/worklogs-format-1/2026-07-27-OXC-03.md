# OXC-03 — Local Oxc pilot in commerce

## What was done

- Selected the clean `commerce` monorepo as the pilot instead of the modified `agency` and `selto` worktrees.
- Added local `link:` development dependencies for `@tala-tools/oxfmt` and `@tala-tools/oxlint`; no package was published.
- Added Oxfmt and Oxlint root configurations plus parallel `oxfmt`, `oxfmt:fix`, `oxlint`, and `oxlint:fix` scripts.
- Configured the storefront's Tailwind stylesheet and ported its existing `better-tailwindcss` ignore patterns.

## Results

- Oxfmt checked 814 storefront files in about 0.72 seconds and reported an initial migration diff of 436 files without modifying them.
- Oxlint loaded the local presets and `eslint-plugin-better-tailwindcss` correctly. Existing custom CSS naming exceptions were respected after porting the ignore list.
- Oxlint reported 51 errors and 765 warnings. The errors were predominantly unused variables (44); the remaining diagnostics were native Oxlint/Next checks not present in the current ESLint baseline.
- `better-tailwindcss` correctness rules work under Oxlint, but its class ordering and line-wrapping rules disagree with Oxfmt's Tailwind sorting. No `--fix` was run to avoid a potential formatter loop.
