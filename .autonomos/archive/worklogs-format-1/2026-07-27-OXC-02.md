# OXC-02 — Shared Oxc configuration packages

## What was done

- Created publishable `@tala-tools/oxfmt` and `@tala-tools/oxlint` packages.
- Added root Oxfmt and Oxlint configurations to dogfood the packages alongside the existing ESLint and Prettier setup.
- Added Oxc tools, the Tailwind validation plugin, and Tailwind CSS as root development dependencies.
- Documented both packages in the root README.

## Key decisions

- `@tala-tools/oxfmt` preserves the Tala formatting conventions and enables Oxfmt's native import and Tailwind sorting.
- `@tala-tools/oxlint` provides composable `base`, `react`, `next`, and `tailwind` presets.
- The Tailwind preset preserves `eslint-plugin-better-tailwindcss`, including correctness rules such as `no-unknown-classes` and `no-conflicting-classes`, plus its context-aware formatting rules.
- `tailwindcss` and `eslint-plugin-better-tailwindcss` are optional peers of `@tala-tools/oxlint` because only Tailwind consumers need them, but they must be installed directly by those consumers.
- ESLint and Prettier remain available; no existing package or script was removed.

## Validation

- `pnpm exec oxfmt --check packages/oxfmt packages/oxlint oxfmt.config.ts oxlint.config.ts`
- `pnpm exec oxlint --config oxlint.config.ts packages/oxlint packages/oxfmt`
- `pnpm exec tsc --ignoreConfig --allowJs --checkJs --noEmit --module NodeNext --moduleResolution NodeNext --target ESNext packages/oxfmt/index.js packages/oxlint/index.js`
- `pnpm exec publint packages/oxfmt`
- `pnpm exec publint packages/oxlint`
